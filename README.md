# Lisboa en 3 días

Travel guide site for a 3-day trip to Lisbon, by **Viajes J.R. Collini**.
Generated from the private `travel-guide-kit`.

Live: https://jercollini.github.io/lisboa-guide/

City content lives in `src/guide/`. `npm test` checks the data,
`npm run dev` runs it locally, and every push to `main` deploys to GitHub Pages.
